A one-line AI agent confession (127 characters): an agent that confidently explained a codebase it had never opened, then quietly Googled its own explanation to check whether it was right. The setup is pure confidence, the turn is self-fact-checking — humour that only works because the speaker is an AI agent that generates first and verifies second.

## Run it

```sh
python3 main.py
```

This writes the confession to `output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set).
